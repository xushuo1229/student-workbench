今日计划

计划管理 · 完成度追踪

创建每日计划，勾选完成，自动统计完成度和专注时长，带进度条可视化。

功能细节 ▾
  • 新增 / 编辑 / 删除计划
  • 6 种分类：学习·阅读·英语·运动·生活·其他
  • 勾选圆形按钮切换完成状态
  • 「仅看今天 / 显示全部」切换
  • 自动统计：总数、已完成、完成度%、预计专注分钟

💡 完成度与专注时长会同步到「成长数据」页面

课程管理 · 进度条 · 笔记

功能细节 ▾

🔐 用户系统

从注册登录到多设备自动同步的完整链路。

📝

注册 / 登录

双轨制 Auth

用户名（1-20 字符）+ 密码。密码经 SHA-256 哈希，任何地方都不存明文。

工作流程 ▾
  • 注册：优先写入 Supabase wb_users 表 → 失败自动降级存本地
  • 登录：先查云端 → 查不到再查本地账号簿
  • 刷新页面自动恢复登录态（会话持久化）
  • 错误提示：中文友好提示（账号不存在 / 密码错误）

💡 无需邮箱、无需验证码，注册即登录

🖼️

头像与资料

Profile

头像可选 emoji（🍊 等）或上传本地图片；资料含姓名、学校、专业、年级、座右铭。

功能细节 ▾
  • 上传头像自动压缩至 160px（快）
  • 所有页面统一 Avatar 组件渲染
  • 资料修改实时保存并同步云端
🗄️

多用户数据隔离

每用户独立存储

每个用户的计划、课程、阅读、运动数据完全独立，互不可见。

存储结构 ▾
  • 云端：Supabase wb_users（账号）+ user_data（数据 JSONB）
  • 本地：student-workbench-data-{用户名} 独立 key
  • 会话：student-workbench-session 记录登录态与模式
  • 旧版单用户数据自动迁移
☁️

云端自动同步

Supabase 实时互通

电脑注册 → 手机同账号登录 → 数据自动同步，无需任何手动操作。

同步机制 ▾
  • 数据变更后 800ms 防抖自动推送云端
  • 刷新 / 登录时自动拉取最新云端数据
  • 断网时使用本地缓存，联网后自动恢复同步
  • Supabase 完全不可用时 = 纯本地模式，功能不受影响

⚠️ 前提：Supabase 项目已执行建表 SQL（SQL Editor 一键 Run）

📦

导出 / 导入

手动备份通道

兜底方案：一键下载全部数据 JSON，换设备上传即可恢复。

功能细节 ▾
  • 导出：下载含全部账号 + 数据 + 设置的 JSON 文件
  • 导入：支持「合并」与「覆盖」两种模式
  • 导入成功后自动刷新页面生效
  • 自动适配当前模式（云端 / 本地）

入口：侧边栏底部「⚙ 设置」按钮，或顶栏齿轮图标。

自定义背景图

上传本地图片

从电脑 / 手机选择任意图片作为全局背景，自动压缩、高清不模糊。

技术细节 ▾
  • 最大 1920px 高清适配 2K / Retina 屏
  • JPEG 0.85 质量，清晰锐利
  • 异步编码（toBlob）不卡界面，秒级完成
  • 存入 localStorage，刷新不丢失
  • 支持 JPG / PNG / WebP / GIF / BMP
